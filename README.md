# Flows prototype

Static copy of the Flows prototype screens, published for user testing.

**Built, not edited.** The source lives in `Jimdo/ai-product-intelligence`
under `design-system/`. Regenerate with:

```
node data/scripts/publish-prototype.js --out=../flows-prototype --base=/flows-prototype/
```

Paths are rewritten for a project page, so this bundle only works when served
from `/flows-prototype/`. Changes made here are lost on the next build.

Published at https://jimdo.github.io/flows-prototype/
